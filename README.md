# **CarDekho - Used Car Price Prediction with Streamlit Integration**

**Problem Statement:**

1.) The "CarDekho Used Car Price Prediction" project aims to accurately estimate the price of used cars based on multiple features.

2.) The project involves data preprocessing, feature engineering, model building, and deployment using a Streamlit interface.

3.) By enabling users to input car details and receive instant price predictions, the project improves decision-making for buyers and sellers.

----

**Features**

* **Data Cleaning & Transformation**: Processed features such as Kms\_Driven, Fuel\_Type, Transmission, and Owner for model readiness.
* **Model Training & Evaluation**: Trained and compared algorithms like Random Forest, Linear Regression, and XGBoost.
* **Model Serialization**: Saved the best-performing XGBoost model using Joblib for deployment.
* **Streamlit Deployment**: Built an interactive UI using Streamlit to predict car prices based on user inputs.

---

**Tools**

Python, Pandas, NumPy, Scikit-learn, XGBoost, Joblib, Matplotlib, Seaborn, Streamlit

---

**Approach**

* **Python**: Used for complete scripting and model development.
* **Pandas/NumPy**: For feature engineering, imputation, and transformation.
* **Scikit-learn & XGBoost**: For training and evaluating multiple regression models.
* **Joblib**: To serialize the best-trained model for efficient deployment.
* **Streamlit**: For building the user-facing prediction app.
* **Matplotlib & Seaborn**: Used for EDA and visualizing feature impact on car pricing.

---

**Findings**

Findings → Performed detailed analysis to understand how various factors (like car age, fuel type, and seller type) affect resale value; successfully predicted used car prices with high accuracy.
